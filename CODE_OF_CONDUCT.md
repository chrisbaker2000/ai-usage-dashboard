# Code of conduct

This is a small personal project. Be respectful in issues and pull requests, and assume good faith.

Harassment, personal attacks, and posting someone else's credentials, session files, or account
identifiers are not welcome.

Report a conduct problem by opening a GitHub issue. Report a vulnerability through a private
advisory, as [SECURITY.md](SECURITY.md) describes. The maintainer may edit, hide, or block a
contribution that breaks this.
